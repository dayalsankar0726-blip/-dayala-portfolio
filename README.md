# Dayala Portfolio

Personal UX design portfolio with enterprise SaaS, operations, and AI product case studies.

## Run locally

From the project folder, run:

```sh
python3 -m http.server 3000 --bind 127.0.0.1
```

Open http://127.0.0.1:3000 in your browser. No build step is required.

## Pages

- `index.html` — portfolio homepage
- `case-tractor-connect.html` — Tractor Connect
- `case-staff-dashboard.html` — Bakery Order Operations
- `case-billora-ai.html` — Billora AI

Shared styles, scripts, and images are in `assets/`.
